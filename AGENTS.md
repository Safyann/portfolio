# AGENTS.md

Портфолио Алёны Сафьянниковой. Спецификация — `docs/spec.md` (локальная, в репозиторий не входит).

## Архитектура

- Next.js (App Router), статический экспорт (`output: 'export'`) → папка `out/`.
- Маршруты — в `app/`, код — в `src/` по Feature-Sliced Design: `shared` → `entities` → `features` → `widgets`. Слой импортирует только нижележащие слои; наружу модуль отдаёт API через `index.ts`.
- Внутри слайса: `model/` — типы, `lib/` — логика, `ui/` — компоненты, `test/` — тесты.
- Стили — SCSS Modules рядом с компонентом; цвета и отступы — CSS-переменные из `src/shared/styles/global.scss`.

## Контент

- Кейсы — `src/entities/case/lib/cases.ts`, другие проекты — `side-projects.ts`.
- Только факты из резюме и собственных коммитов Алёны. Не придумывать метрики и формулировки задач.
- Скриншоты — только публичных страниц.

## Команды

- `npm run dev` — разработка, `npm run build` — сборка в `out/`.
- Перед коммитом: `npm run lint && npm run typecheck && npm test`.

## Стиль кода

Корпоративный baseline: `.prettierrc`, точки с запятой, одинарные кавычки, `===`, фигурные скобки у всех `if`, без `any`.
